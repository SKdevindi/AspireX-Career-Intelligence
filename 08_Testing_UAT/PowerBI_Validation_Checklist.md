# AspireX – Power BI Dashboard Validation Checklist

## 1. Introduction

This document defines the validation checks required to verify the accuracy and reliability of AspireX Power BI dashboards.

## 2. Dashboard Validation Checklist

### 2.1 Data Accuracy
- [ ] Verify that the dashboard displays the correct sample dataset.
- [ ] Check whether all required records are displayed.
- [ ] Verify that there are no duplicate records.
- [ ] Check for missing or incorrect values.

### 2.2 Career Readiness Dashboard
- [ ] Verify that the selected career is displayed correctly.
- [ ] Check whether the career readiness score is calculated correctly.
- [ ] Verify that the displayed KPIs match the sample data.

### 2.3 Skills Gap Dashboard
- [ ] Verify that missing skills are displayed correctly.
- [ ] Check whether required and current skills are compared accurately.
- [ ] Verify the total number of skill gaps.

### 2.4 Learning Progress Dashboard
- [ ] Verify completed learning activities.
- [ ] Check the learning progress percentage.
- [ ] Ensure that progress charts reflect the sample data.

### 2.5 Visualizations and Filters
- [ ] Verify that charts display the correct information.
- [ ] Check that dashboard filters work correctly.
- [ ] Verify that KPI cards update when filters change.
- [ ] Check dashboard readability and consistency.
