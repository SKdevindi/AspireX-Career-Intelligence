04 — Business Process Models

This folder contains the business process models and workflow diagrams for the AspireX — Intelligent Career Readiness & Skills Gap Analysis Platform.

Purpose

To visualize and analyze how users interact with the proposed AspireX platform and how its main business processes work.

Planned Documents

1. AS-IS Process Diagram — Illustrates the current career planning process without AspireX.
2. TO-BE Process Diagram — Illustrates the improved career planning process using AspireX.
3. BPMN Diagrams — Represent business processes, activities, decisions, and workflows.
4. Process Improvement Analysis — Identifies problems in the current process and explains the proposed improvements.

Key Business Processes

- Student career goal identification
- Existing skills assessment
- Target career selection
- Skills gap analysis
- Learning recommendations
- Career development progress tracking

Tools

- Draw.io (diagrams.net)
- BPMN 2.0

Status

Planned — Process diagrams and analysis documents will be added during the project.
