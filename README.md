# AspireX – Intelligent Career Readiness & Skills Gap Analysis Platform

## 1. Project Overview

**AspireX** is an intelligent career readiness and skills gap analysis platform designed to help university students evaluate their current skills, identify gaps between their existing capabilities and career requirements, and discover relevant learning opportunities.

The platform aims to support students in making informed career decisions by providing insights into their career readiness and recommending learning resources to improve their skills.

This project focuses on applying Business Analysis concepts and techniques to identify business needs, define requirements, model business processes, design user interfaces, and analyse data through interactive dashboards.

## 2. Problem Statement

University students often face difficulties understanding whether their current skills meet the requirements of their desired careers.

Some common challenges include:

- Lack of awareness of industry-required skills.
- Difficulty identifying personal skill gaps.
- Limited guidance when selecting relevant learning resources.
- Difficulty tracking learning progress.
- Lack of a clear overview of career readiness.

AspireX aims to address these challenges by providing a structured approach to career readiness assessment and skills gap analysis.

## 3. Project Objectives

The main objectives of AspireX are to:

- Help students identify their target careers.
- Evaluate students' existing skills and proficiency levels.
- Compare student skills with career-required skills.
- Identify missing and underdeveloped skills.
- Recommend relevant learning resources.
- Support students in tracking their learning progress.
- Present career readiness insights through interactive dashboards.

## 4. Key Features

### 4.1 Career Selection
Allows students to identify and select their desired career path.

### 4.2 Skill Profile Management
Maintains information about students' existing skills and proficiency levels.

### 4.3 Skills Gap Analysis
Compares students' existing skills against the skills required for their selected careers.

### 4.4 Learning Recommendations
Provides relevant learning resources to help students improve their skills.

### 4.5 Learning Progress Tracking
Supports monitoring students' learning activities and completion progress.

### 4.6 Career Readiness Dashboard
Presents student and career-related insights using interactive Power BI visualizations.

## 8. Dataset

The project uses a sample dataset containing fictional student and career-related information.

The dataset includes the following tables:

| Table | Description |
|---|---|
| Students | Student information and target careers |
| Careers | Available career paths |
| Skills | Skill information |
| StudentSkills | Students' skills and proficiency levels |
| CareerRequiredSkills | Skills associated with each career |
| LearningResources | Learning resources linked to skills |
| LearningProgress | Student learning progress information |

The dataset is intended for project demonstration and analysis purposes. It does not contain real student records.
