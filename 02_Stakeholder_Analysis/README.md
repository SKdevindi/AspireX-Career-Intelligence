02 — Stakeholder Analysis

This folder contains the stakeholder identification and analysis documents for the AspireX — Intelligent Career Readiness & Skills Gap Analysis Platform.

Purpose

To identify key stakeholders, understand their needs and expectations, and analyze their influence and interest in the AspireX project.

Planned Documents

1. Stakeholder Register— Lists the stakeholders, their roles, responsibilities, and interests.
2. Stakeholder Analysis — Identifies stakeholder needs, expectations, and influence on the project.
3. Power-Interest Matrix — Categorizes stakeholders based on their level of power and interest.
4. User Personas — Describes fictional target users, their goals, needs, and challenges.
5. Stakeholder Communication Plan — Defines how project stakeholders would receive information and updates.

 Key Stakeholders

- University Students
- Fresh Graduates
- Career Advisors
- University Career Guidance Units
- System Administrators
- Project Owner / Business Analyst

 Tools and Techniques

- Stakeholder Register
- Power-Interest Matrix
- User Persona Analysis
- Stakeholder Mapping

 Status

In Progress — Stakeholder analysis documents will be added during the project.

## Note

AspireX is a fictional Business Analysis portfolio project. The stakeholders and personas are based on illustrative scenarios rather than actual stakeholder interviews.
