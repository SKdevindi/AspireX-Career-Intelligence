# 05 — System Design

This folder contains the proposed system design documentation for the **AspireX — Intelligent Career Readiness & Skills Gap Analysis Platform**.

## Purpose

To define the system structure, user interactions, data relationships, and major components required to support AspireX functionality.

 Planned Documents

1. Use Case Diagram — Illustrates interactions between users and the system.
2. Entity Relationship Diagram (ERD) — Defines database entities and their relationships.
3. System Architecture Diagram — Provides a high-level view of the proposed system components.
4. Data Dictionary — Describes important data entities, attributes, and data types.

 Key System Components

- User Management
- Skills Management
- Career Path Management
- Skills Gap Analysis
- Learning Recommendation Module
- Career Readiness Dashboard
- Progress Tracking

 Tools

- Draw.io (diagrams.net)
- Figma
